- Updates now come from the public download page, so every copy can find them
- Updates itself: checks once a day, verifies the download's SHA-256, installs in the background and restarts
- **Share** opens the Windows share sheet (Nearby Sharing, WhatsApp, Mail, Teams…) for every dropped file
- **Any key** can open a wheel: left/right modifiers, the Windows key, F1–F24, mouse side buttons, or record any key (Fn and Command on a Mac)
- **Compression levels** for PDF, audio, video, ZIP and 7Z, each showing the size it will make before you save
- **Several files at once**: Edit, Crop, Add BG, Metadata, Protect, video Crop, Speed, Channels and Visualizer apply to every dropped file
- **Settings**: Save / Cancel (closing without saving puts everything back), rounded dropdowns and menus
- **Lighter and faster**: about 89 MB in use instead of 139 MB; the Liquid glass wheel draws in 1 ms instead of 11 ms
- **macOS**: Apple silicon and Intel builds (.dmg)
