- Fixes updates that never installed, and the wheel opening while you select files
- **Updates**: *Update now* really installs now (earlier versions quit and installed nothing). Each version is offered once, never over a game, and a verified download isn't fetched twice. If an update doesn't finish, ShiftWheel tells you after the restart
- **The wheel opens only when you drag a file first, then tap the key**. Shift then drag selects files as it always did, and rubber-band selection is left alone
- **Knows which app you're in**: by default only File Explorer and other file managers. Chrome, games and editors are left alone. *Settings → Behaviour* can add apps or use every app
- **Stays out of your way**: slows to almost nothing during games and fullscreen apps, and conversions run at low priority
- **Much lighter**: about 7 MB of active memory once idle, instead of about 89 MB. Tools load when used, and memory is given back 30 seconds after you finish
- **Asks before creating many files**: says how many and why, and a PDF split can make one file every N pages. Lots of pieces go in their own folder. Set the limit in *Settings → Saving*
- **About**: privacy, version and system details with *Copy details*, full licence, and *Report a problem* filled in for you
